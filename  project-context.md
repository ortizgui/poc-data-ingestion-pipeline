## 🎯 Expectativas do Projeto (Project Expectations)

### 1. Funcionalidade Principal
- O usuário deve conseguir completar o fluxo de compra em menos de 3 cliques.
- O sistema deve suportar 100 usuários simultâneos sem perda de performance.

### 2. Qualidade de Código
- Espero um código modular onde cada função tenha apenas uma responsabilidade.
- Documentação JSDoc em todas as funções exportadas.

### 3. Experiência do Usuário (UX)
- A interface deve ser minimalista, focada em acessibilidade (WCAG 2.1).
- Feedback visual imediato para cada ação do usuário.
